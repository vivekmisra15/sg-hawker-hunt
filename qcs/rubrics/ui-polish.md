# UI Polish & Delight — Rubric

## Level 1
- Default browser styling
- No animations or transitions

## Level 2
- Basic styling with Tailwind
- Some hover states

## Level 3 (Current)
- Dark/light theme with smooth transitions
- Framer Motion animations (card reveals, panel slides)
- Glass morphism on elevated surfaces
- TypewriterText character reveal in agent panel
- Grade-coloured map markers
- Card-pin sync with selected state

## Level 4 (Target)
- Micro-interactions on all interactive elements
- Loading skeleton states (not just spinners)
- Smooth transitions between search states (idle → searching → results)
- Empty state illustrations (not just text)
- Toast/notification system for non-blocking feedback
- Consistent animation timing (spring configs reused)

## Level 5
- Haptic-feel interactions (spring physics throughout)
- Celebration animation on first result
- Ambient background effects (subtle gradient shifts)
- Sound design (optional, toggle-able)
- 60fps verified on low-end mobile devices
