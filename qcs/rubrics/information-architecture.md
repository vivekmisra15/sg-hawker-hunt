# Information Architecture — Rubric

## Level 1
- Flat list of results with no structure
- No reasoning visibility

## Level 2 (Current)
- Agent reasoning shown in terminal-style panel
- Results ranked with scores
- No collapsible sections or source citations

## Level 3
- Collapsible reasoning sections (expand/collapse per agent)
- Source citations (which API/data source informed each claim)
- Clear visual hierarchy: summary → detail → sources

## Level 4 (Target)
- Inline citations linking claims to data sources
- Structured trace blocks with named sections
- Progressive disclosure: summary first, detail on demand
- Reasoning panel shows data provenance (NEA, Google, RAG)

## Level 5
- Interactive reasoning graph (click to explore agent dependencies)
- Confidence indicators per claim
- Diff view: "what changed since last query"
- Exportable reasoning trace
