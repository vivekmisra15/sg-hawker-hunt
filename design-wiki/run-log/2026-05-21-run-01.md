# Design Wiki Run 01 — 2026-05-21

## Patterns implemented

### Cycle 1: Map interaction (highest delight)

**hotels-02: Bidirectional card↔pin selection sync** (Score: 14)
- `App.tsx`: Added `selectedKey` state, `handleSelect` and `handleMarkerClick` callbacks
- `ResultCard.tsx`: Added `onSelect` prop, `isSelected` visual state (accent border + ring), `data-key` attribute for scroll targeting
- `HawkerMap.tsx`: Added `onMarkerClick` callback, `selectedKey` prop — selected marker opens popup and map pans to it
- `ResultsList.tsx`: Added scroll-to-card on `selectedKey` change via `CSS.escape` + `scrollIntoView`

**zillow-02: Grade-coloured labels on ALL map pins** (Score: 14)
- `HawkerMap.tsx`: Replaced rank-number markers with hygiene grade letter markers. Colour-coded: green (A), amber (B), red (C/D), grey (UNKNOWN/dash). Selected marker scales up (34px → 42px) with glow ring. Exported `markerKey()` utility.

### Cycle 2: Information richness

**hotels-01: Slide-in detail panel** (Score: 13)
- New `StallDetailPanel.tsx`: Full-featured detail panel with rank badge, all status badges, stats grid (distance/rating/score), standout quote blockquote, full reasoning, Google Maps CTA button
- Desktop: slides from right edge, full height, max-w-md
- Mobile: sheet from bottom, 75vh height, rounded top corners, drag handle
- Closes on: Escape key, outside click (with 50ms delay to avoid catching opening click), close button
- ARIA: `role="dialog"`, `aria-modal="true"`, `aria-label` with stall name

### Cycle 3: Filters + context

**zillow-06: Filter strip** (Score: 12)
- New `FilterStrip.tsx`: 5 toggle pills — Michelin, Halal, Open now, Grade A, Under $5
- Active state: filled amber with shadow. Inactive: outlined with border
- `aria-pressed` for accessibility, count indicator when filters active
- `App.tsx`: `applyFilters()` function filters results client-side. Filtered results passed to both ResultsList and HawkerMap

**hotels-04: Time context banner** (Score: 12)
- `App.tsx`: `getTimeContext()` computes current Singapore time (UTC+8) and returns contextual label
- Breakfast (6-11), Lunch (11-15), Dinner (17-21), Supper (21-3)
- Shown as amber-tinted banner between search and results with clock emoji
- Animates in with height transition via Framer Motion
